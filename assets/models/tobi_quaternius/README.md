# Tobi modular — candidato Quaternius

Esta pasta recebe um personagem montado com peças 3D prontas do Quaternius, sem substituir o Tobi atual.

## Composição
- Cabeça e rig: Universal Base Characters / Regular Male OnlyHead.
- Roupa: Modular Character Outfits - Fantasy / Ranger Body, Arms, Legs e Boots.
- Capuz: Ranger Head Hood.
- A cena de montagem fica em res://scenes/characters/tobi_quaternius_candidate.tscn.

## Licenças e fontes
- Universal Base Characters: https://quaternius.com/packs/universalbasecharacters.html
- Modular Character Outfits - Fantasy: https://quaternius.com/packs/modularcharacteroutfitsfantasy.html
- Os dois pacotes declaram CC0 1.0 nas páginas oficiais.

## Estado
- Candidato isolado: não altera a cena principal nem remove o modelo antigo.
- A montagem usa as malhas rigadas do mesmo conjunto humanoide.
- Animações, escala final, encaixe das peças e aparência precisam ser conferidos no Godot antes de qualquer troca do personagem ativo.
- O workflow importa os arquivos glTF, buffers e texturas originais para esta pasta.
